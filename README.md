# Parzival Auto Rater Extension

The **parzival-xol QuickRater** is a Chrome extension that automatically selects a rating and submits a comment on web pages with rating forms.

---

## ✨ Features

- Select a rating from 1 (poor) to 5 (excellent)
- Automatically fills in a matching comment
- Submits the form in one click
- Clean and modern popup design
- Watermark: **Powered by parzival** in the bottom-left corner

---

## 🔧 How to Install

1. Clone or download this repository to your computer.
2. Open Google Chrome and go to `chrome://extensions/`.
3. Enable **Developer mode** (top right corner).
4. Click **Load unpacked**.
5. Select the folder containing this extension.

---

## 📦 Files

- `manifest.json` → Extension configuration  
- `popup.html` → Popup interface  
- `popup.js` → Script handling button clicks and form submission  
- `README.md` → This file

---

## 💬 Usage

1. Click the extension icon in your Chrome toolbar.
2. Choose a rating by clicking one of the buttons.
3. The extension will automatically fill in the rating and submit the form on the current page.
